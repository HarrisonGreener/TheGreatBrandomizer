# The Great Brandomizer

A 3D vintage fruit machine for designers. Pull the handle and the reels spin up a brand profile: a theme-based colour palette (5 to 7 colours) and a Google Fonts headline and body pairing, with WCAG contrast checks. Hold the reels you like, re-spin the rest, and cash out a printed brand card.

Built with [three.js](https://threejs.org/). Open `index.html` in a browser; no build step.

## Features

- 16 themes, from Sixties to Grunge, each with its own colour rules, fonts and a rare "house pick" jackpot
- Colour reels and font reels that physically spin, with HOLD buttons under each
- A tattooed arm that reaches in and pulls the handle
- Cash Out prints a brand card into the tray, with hex codes, contrast results, CSS variables and a font embed
- Limited free camera, plus Machine, Reels and Tray views
- Saved spins (stored in your browser)

`prototype-1.html` is the first 2D version.
